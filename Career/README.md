# SIDDHAN TECHNOLOGIES | 3D, Game Art & Creative Media Career Directory

A state-of-the-art, high-performance web application designed for students, 3D artists, game developers, animators, riggers, video editors, colorists, and recruiters — **mobile-first responsive and engineered for all devices**, branded as **SIDDHAN TECHNOLOGIES**.

This platform catalogs **85 specialized industry production roles** across **11 core software suites**, mapping out the entire career landscape for AAA Video Games, Feature Film VFX & OTT, Photorealistic Architectural Visualization, Digital Fashion, Video Editing, Motion Graphics, and Audio Engineering.

## 📱 Mobile-First Features

### 1. 📲 App-Style Fixed Bottom Navigation Bar
- Seamless one-thumb navigation bar fixed at the bottom on all smartphone screens (`max-width: 768px`):
  - 🎴 **Roles**: Instant catalog card browser.
  - 📋 **Matrix**: Master spreadsheet table.
  - 📊 **Analytics**: Market share breakdown & production hub rankings.
  - 🧭 **Pipelines**: Studio production workflows.
  - 🔖 **Saved**: Instant access to your personal shortlist with live counter badge.
- Native safe-area-inset support for iPhone notch/home indicators and bezel-less Android displays.

### 2. 🗂️ Mobile Filter Bottom Sheet
- Clean mobile search toolbar featuring a dedicated **Filters** button with active filter counter indicator.
- Tapping it slides up a native iOS/Android style **Bottom Sheet Drawer** to filter by any of the 11 Software Suites, Industries, Production Hubs, or Sort Orders.

### 3. 👆 Horizontal Swipeable Software Strip
- Touch-friendly, momentum-based swipeable software pills at the top for all 11 suites (`All`, `UE5`, `Max`, `Maya`, `Substance`, `Nuke`, `Photoshop`, `Resolve`, `MD`, `Premiere`, `AE`, `Audition`) with active neon glows and live role counts.

### 4. 📄 Bottom Sheet Modals with Pull Handles
- Role blueprints, career matcher quiz, and shortlist drawers slide up smoothly from the bottom on mobile devices with visual grab handles and sticky action footers.

- **Market Share Visualizer**: Live percentage bars for all 11 software suites.
- **Top Production Hub Ranking**: Ranked list of leading production cities with active role counts.

### 4. 🧭 Production Pipeline Roadmaps

2. **Feature Film & High-End VFX Pipeline** (Matchmove -> Modeling -> Rigging -> Cloth -> Animation -> LookDev -> Nuke Compositing)
3. **Video Post-Production & Color Finishing Pipeline** (Ingest/Dailies -> Edit in Premiere/Resolve -> Sound in Audition -> Motion in AE -> DI Grading in Resolve)
4. **ArchViz & Real-Time Digital Twin Pipeline** (CAD Blueprints -> 3ds Max Structures -> Soft Goods -> Corona Renders -> UE5 Pixel Streaming)
5. **Digital Fashion & Virtual Retail Pipeline** (2D Pattern Cuts -> Fabric Physics Simulation -> PBR Weave Textures -> Game Quad Retopology -> Metaverse Presentation)

### 5. ⚖️ Side-by-Side Role Comparison Matrix
- Compare up to 3 roles simultaneously.
- Direct side-by-side analysis of responsibilities, tool stacks, hubs, and demand ratings.

### 6. ⚡ Interactive Career Pathway Matcher (3-Step Quiz)
- Interactive wizard matching artistic vs. technical preferences and creative passion to the best-suited career roles with instant recommendations.

### 7. 💾 Personal Shortlist & Multi-Format PDF Export System
- Bookmark roles to browser `localStorage` with real-time badge counters.
- 📄 **Single Role Blueprint PDF Export**: Dedicated "PDF Blueprint" buttons inside the **View Blueprint** modal (both in the header and footer) to instantly generate and download a single-page vector specification sheet for any of the 85 roles.
- 📕 **Executive Vector PDF Export (`Download PDF`)**: Generates an A4 portrait vector dossier using local `jspdf.umd.min.js` (100% offline-ready, zero canvas rasterization) with branded headers, matrix index, role breakdown cards, companion tool chips, portfolio guidance, and hub listings.
- 🖨️ **Native Print & Save as PDF (`Print / Save PDF`)**: Zero-dependency print view formatted with `@page` styling for Chrome/Edge/Firefox "Save as PDF" dialogue.
- 📊 **CSV Spreadsheet Export (`Export CSV`)**: Formatted data table ready for Microsoft Excel, Apple Numbers, and Google Sheets.
- 📋 **JSON Export (`Export JSON`)**: Clean JSON format for developer workflows and ATS imports.
- Global trigger: Direct "Export Saved Roles as PDF" link in the footer and Saved Drawer.
